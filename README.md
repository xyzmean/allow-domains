# allow-domains

Списки доменов, подсетей и AS номеров для BGP анонсирования.

## Структура

```
sources/
├── domains/   # домены для DNS резолва
├── subnets/   # готовые подсети (IPv4)
└── asn/       # AS номера (устарело, AS определяются автоматически)
```

## Использование

Репозиторий используется как submodule в [bgp_russia](https://github.com/xyzmean/bgp_russia).

## Формат файлов

- `domains/*.lst` - домены (по одному на строку)
- `subnets/*.lst` - подсети в CIDR (по одной на строку)
- `asn/*.lst` - AS номера (устарело)

AS номера определяются автоматически через RIPE API при генерации BGP конфига.
